COREX — E-commerce de Hardware Gamer

PROBLEMAOferecer uma plataforma de e-commerce completa para hardware e periféricos gamer — do catálogo de produtos ao checkout — com painel administrativo para gestão de produtos, categorias e pedidos.

ARQUITETURAMonorepo em três camadas: API REST em Spring Boot (autenticação, regras de negócio e persistência), SPA em React consumindo a API, e banco PostgreSQL.

DECISÕES TÉCNICASAutenticação JWT com senhas em BCrypt e autorização por papéis (ADMIN/CLIENT), upload de imagens via Cloudinary, cálculo de frete com preenchimento automático de endereço por CEP, e ambiente containerizado com Docker Compose.

RESULTADOCarrinho persistente, ciclo completo de pedidos com rastreamento de status, painel admin para produtos/categorias/pedidos e deploy público com demo ao vivo.
